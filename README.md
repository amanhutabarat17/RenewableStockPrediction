# RenewableStockPrediction
This is a system to predict stock price in 2 Renewable Company in Indonesia (ARKO & KEEN) using two algorithm (Random Forest Regression and Exponential Moving Average).
The first thing you can do is excel that have data list stock price from the company
Then you should to upload that excel to the system, bumhh...the result is showing.
You can also setting some parameter like deepth and how many trees in Random Forest Method.
